## 🔢 编码规则调整

### v1.1修正后的编码公式

**IP编码**:
```
IP网段 = 10.B.C.0/21
其中:
- B = 区域码 × 10 + 9
- C = (业务代码 - 1) × 8  ← 修正公式
```

**示例验证（门禁，业务代码2）**:
```
东校区: B = 1×10+9 = 19, C = (2-1)×8 = 8 → 10.19.8.0/21 ✅
西校区: B = 2×10+9 = 29, C = (2-1)×8 = 8 → 10.29.8.0/21 ✅
南校区: B = 3×10+9 = 39, C = (2-1)×8 = 8 → 10.39.8.0/21 ✅
```

**VLAN编码**（无变化）:
```
VLAN号 = 区域码 × 1000 + 900 + 业务代码 × 10
```
