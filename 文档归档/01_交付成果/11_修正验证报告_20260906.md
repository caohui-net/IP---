## 五、编码规则确认

### 5.1 主业务区编码规则

```
IP前缀 = 10.B.C.D
其中:
  B = 区域码 × 10 + 业务代码
  区域码: 东=1, 西=2, 南=3
  业务代码: 1-4, 6-8

VLAN ID = 区域码 × 100 + (业务代码 + 区域偏移)
  东校区: 101-108, 166
  西校区: 201-208, 266
  南校区: 301-308, 366
```

### 5.2 物联网区编码规则（版本B）

```
IP前缀 = 10.B.C.0/21
其中:
  B = 区域码 × 10 + 9
  C = (业务代码 - 1) × 8
  业务代码: 1-6

VLAN ID = B × 100 + 业务代码 × 10
示例:
  东校区安防监控: VLAN 1910 (19×100 + 1×10)
  西校区智能门禁: VLAN 2920 (29×100 + 2×10)
  南校区环境感知: VLAN 3930 (39×100 + 3×10)
```
