### 执行顺序
1. **Phase 1**: 新增VLAN和IP段(不影响现网)
2. **Phase 2**: 配置DHCP服务器和中继
3. **Phase 3**: 迁移终端设备
4. **Phase 4**: 删除旧配置
5. **Phase 5**: 验证和清理

### 执行间隔

- SVI配置后等待: 10秒
- DHCP配置后等待: 30秒

- **延迟回退**: P1问题(部分功能受影响)在维护窗口处理
- **回退时限**: 每个批次30分钟内必须决定是否回退

#### 方案B: 按校区+业务细分配置（18个VLAN）⭐ 推荐

##### 设计理念
参考楼栋SuperVLAN设计，按**校区×业务**双维度隔离：
- 3个校区 × 6类业务 = 18个VLAN
- 统一使用/21网段（2046地址/业务）
- 业务隔离：门禁故障不影响监控
- 地址充足：大业务（监控）预估500+设备

##### VLAN编码规则
```
VLAN号 = 区域码 × 1000 + 900 + 业务代码 × 10
IP网段 = 10.B.C.0/21，其中 B = 区域码×10+9，C = 业务代码×8

示例（门禁系统）:
- 东校区: VLAN 1920 = 1×1000+900+2×10, IP 10.19.8.0/21
- 西校区: VLAN 2920 = 2×1000+900+2×10, IP 10.29.8.0/21
- 南校区: VLAN 3920 = 3×1000+900+2×10, IP 10.39.8.0/21
```
