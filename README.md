## 📋 项目简介

本项目是为三校区（东/西/南校区）校园网络进行全面IP地址和VLAN规划重构，建立统一编码体系，解决现网IP冲突、VLAN混乱等问题，并为物联网业务预留扩展空间。

### 项目范围

- **地理范围**: 东、西、南三个校区
- **业务覆盖**: 7大类主业务 + 6类物联网业务
- **地址规模**: 36,828个物联网地址 + 主业务地址池
- **设备覆盖**: 三校区核心交换机、接入交换机、服务器区

### 项目目标

1. 建立统一的IP/VLAN编码体系
2. 解决现网9项P0/P1问题
3. 消除IP冲突和路由黑洞
4. 为物联网业务提供18个VLAN支持
5. 建立完整的IPAM源数据表
6. 提供生产就绪的配置和部署方案

## 🎯 编码规则速查

### IP地址编码

```
格式: 10.B.C.D

B = 区域码 × 10 + 业务码

区域码:
  东(1) → 11-19 → VLAN基100
  西(2) → 21-29 → VLAN基200
  南(3) → 31-39 → VLAN基300

业务码（主业务）:
  教师有线: 1
  教师无线: 2
  学生有线: 3
  学生无线: 4
  访客: 7
  设备管理: 8

业务码（物联网）: 9
  B = 19, 29, 39（物联网业务）
```

### VLAN编码

```
主业务VLAN = 区域码×100 + 业务码
  东校区教师有线: 101
  西校区学生有线: 203
  南校区访客: 307

物联网VLAN = 区域码×1000 + 900 + 业务码×10
  东校区物联网: 1910-1960 (6个业务)
  西校区物联网: 2910-2960
  南校区物联网: 3910-3960
```

### 网关规则

```
统一采用: 网段末端/24的.254

例如: 
  10.31.0.0/21 → 网关 10.31.7.254
  10.31.8.0/21 → 网关 10.31.15.254
```
