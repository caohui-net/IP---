## 🔍 编码规则速查

### IP地址
```
格式: 10.B.C.D
B = 区域码 × 10 + 业务码

东校区(1): 11-19
西校区(2): 21-29
南校区(3): 31-39
物联网: 19, 29, 39
```

### VLAN
```
主业务: 区域码×100 + 业务码
  东: 101-109
  西: 201-209
  南: 301-309

物联网: 区域码×1000 + 900 + 业务码×10
  东: 1910-1960
  西: 2910-2960
  南: 3910-3960
```

### 网关
```
统一: 末端/24的.254
示例: 10.31.0.0/21 → 10.31.7.254
```

### 物联网方案
```
6类业务 × 3校区 = 18个VLAN
统一/21容量 = 每VLAN 2046地址
总地址: 36,828个
```
