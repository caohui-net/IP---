# .archive 归档目录说明

**目录用途**: 存放详细的归档记录和项目管理文档（不常用）

---

## 📁 目录结构

```
.archive/
├── 项目文档/              # 项目管理文档（3个）
│   ├── task_plan.md      # 9阶段任务计划
│   ├── progress.md       # 项目进度日志
│   └── findings.md       # 项目发现与研究记录
│
└── 归档元数据/            # 归档过程记录（7个）
    ├── 项目交接清单.md
    ├── 项目归档索引.md
    ├── 归档完成报告.md
    ├── 归档总结.md
    ├── 文档重组报告.md
    ├── 归档完成-最终报告.md
    └── ARCHIVE_MANIFEST.txt
```

**总计**: 10个文件

---

## 📝 文件说明

### 项目文档（项目管理）

- **task_plan.md** - 详细的9阶段任务计划，包含T-01到T-12待确认事项
- **progress.md** - 项目进度日志，记录Session 1-2的工作内容
- **findings.md** - 项目发现与研究记录，包含需求分析和风险评估

### 归档元数据（归档过程）

- **项目交接清单.md** - 完整的交接文档，包含验证清单和联系人
- **项目归档索引.md** - 详细的文件导航和统计
- **归档完成报告.md** - 归档验证报告
- **归档总结.md** - 归档总结
- **文档重组报告.md** - v1.0→v1.1重组说明
- **归档完成-最终报告.md** - 最终确认报告
- **ARCHIVE_MANIFEST.txt** - 纯文本归档清单

---

## 🔍 使用场景

### 查看项目管理细节

```bash
cat .archive/项目文档/task_plan.md    # 任务计划
cat .archive/项目文档/progress.md     # 进度日志
```

### 查看归档过程

```bash
cat .archive/归档元数据/项目交接清单.md
cat .archive/归档元数据/归档完成-最终报告.md
```
