## VLAN编码规则（v3.0扩展）

### 公式
```
VLAN号 = (区域码×1000 + 900) + 业务代码×10
```

### 区域码定义
- 东校区: 1
- 西校区: 2
- 南校区: 3

### 编码示例

#### 门禁系统（业务代码=2）
- 东校区: 1×1000 + 900 + 2×10 = **1920**
- 西校区: 2×1000 + 900 + 2×10 = **2920**
- 南校区: 3×1000 + 900 + 2×10 = **3920**

#### 视频监控（业务代码=1）
- 东校区: 1×1000 + 900 + 1×10 = **1910**
- 西校区: 2×1000 + 900 + 1×10 = **2910**
- 南校区: 3×1000 + 900 + 1×10 = **3910**

#### 消防系统（业务代码=5）
- 东校区: 1×1000 + 900 + 5×10 = **1950**
- 西校区: 2×1000 + 900 + 5×10 = **2950**
- 南校区: 3×1000 + 900 + 5×10 = **3950**

## IP地址分配方案

### 方案说明
每个业务类别在每个校区分配独立的/24网段

### 编码规则
```
IP网段 = 10.B.C.0/24
其中:
- B = 区域码×10 + 9（物联网区标识）
- C = 业务代码×10
```

## 业务分类依据

### 参考来源
1. **智慧校园物联网标准分类**（2026）
   - [IoT设备分类](https://iot.sakura.ad.jp/column/iot-device/)
   - [物联网设备安全检测综述](https://crad.ict.ac.cn/article/doi/10.7544/issn1000-1239.202330482)

2. **校园实际需求**
   - 安防监控（视频监控、门禁、消防）
   - 环境控制（环境监测、智能照明）
   - 能源管理（电表、水表、能耗）
   - 教学支持（智能教学设备）
   - 设施管理（电梯、停车、巡更）
   - 健康医疗（体温检测、医疗监测）

### 分类原则
1. **业务独立性**: 每类设备功能独立
2. **管理分离**: 不同部门管理
3. **安全隔离**: 关键系统独立VLAN
4. **扩展性**: 预留足够地址空间
5. **不超过9类**: 符合用户要求

## 与v3.0编码规则的关系

### 原v3.0规则
```
B = 区域码×10 + 业务码
```

### 物联网扩展规则
```
VLAN = 区域码×1000 + 900 + 业务代码×10
IP第二段 = 区域码×10 + 9
IP第三段 = 业务代码×10
```

### 一致性
- 物联网区标识: B段使用19/29/39（符合"区域码×10+9"）
- VLAN编码: 使用1900+/2900+/3900+系列（清晰区分）
- 业务隔离: 每个业务独立VLAN和IP段
